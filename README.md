# WindowSeat

A full stack application that recommends optimal flight seats for viewing landmarks along an estimated flight path based on weather conditions, scenic landmarks, and AI analysis.

## Features
- **Smart Seat Recommendations**: AI-powered analysis considering weather, landmarks, and flight paths
- **Algorithmic Estimation**: Uses an algorithim to obtain flight path check possible landmarks along the route
