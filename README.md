# WindowSeat

A full stack app that recommends which side of the plane to sit on for the best views.

## About the Project

I fly alot and I love looking at the stunning views Earth has to offer from the window seat. Sometimes the NYC skyline at night was right in front of me, other times we saw nothing because I picked the wrong side of the plane.

There's no way to figure out which side to sit on unless you've flown the exact route before, and even then, nothing really gives you odds or shows you what's along the way. So I built this as a way to empower fellow window seat lovers like me!

## Features

- Great circle flight path estimation with landmark detection
- Sun position and glare analysis
- Weather and cloud cover data along the route
- AI-powered seat recommendation with GPT-4o-mini
- Interactive map visualization
